# C++ Core Concepts

This directory contains examples of foundational C++ concepts that apply across multiple language standards.

## Examples

- `classes_raii_examples.cpp` - classes, destructors, and RAII
- `copy_move_examples.cpp` - copy and move constructors and assignments
- `const_correctness_examples.cpp` - const objects, methods, and references
- `pointers_references_examples.cpp` - pointers, references, and `nullptr`
- `inheritance_polymorphism_examples.cpp` - virtual functions and polymorphism
- `operator_overloading_examples.cpp` - custom operators and stream output
- `namespaces_examples.cpp` - namespaces and header/source separation
- `templates_examples.cpp` - function and class templates
- `crtp_examples.cpp` - static polymorphism with the Curiously Recurring Template Pattern
- `exceptions_examples.cpp` - throwing, catching, and exception hierarchies
- `containers_examples.cpp` - standard container selection
- `containers_algorithms_examples.cpp` - containers and standard algorithms
- `function_objects_examples.cpp` - function pointers, functors, and `std::bind`
- `iterators_callables_examples.cpp` - iterators, lambdas, and function objects
- `ownership_lifetime_examples.cpp` - borrowing, ownership, and object lifetime
- `casts_examples.cpp` - `static_cast` and `dynamic_cast`
- `initialization_lifetime_examples.cpp` - initialization order and scope lifetime
- `undefined_behavior_examples.cpp` - bounds, overflow, and pointer safety

Compile these examples with C++11 or a later standard.
