# C++ Learning Repository

This repository is a learning workspace for exploring C++ language features across different standards.

## Structure

- `cpp_11/` - examples and exercises for C++11 features.
- `cpp_14/` - examples and exercises for C++14 features.
- `cpp_17/` - examples and exercises for C++17 features.
- `cpp_20/` - examples and exercises for C++20 features.

## Purpose

The repository is organized to help practice and understand modern C++ concepts, idioms, and standard library enhancements. Each folder contains sample code, small projects, or experiments focused on the corresponding C++ standard.

## Usage

1. Open the folder for the C++ standard you want to study.
2. Review and run the example source files.
3. Modify or add new examples to explore additional features.

## Notes

- This repository is intended for learning and experimentation, not production-ready code.
- Use a compatible compiler with the appropriate standard flag, such as `-std=c++11`, `-std=c++14`, `-std=c++17`, or `-std=c++20`.
